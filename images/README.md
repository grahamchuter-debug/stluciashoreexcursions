# Images — St Lucia Shore Excursions

Replace placeholder photos with St Lucia–specific assets before launch.

## Recommended files

| File | Use |
|------|-----|
| `favicon.ico` | Site favicon (16×16 / 32×32) |
| `hero-pitons.jpg` | Homepage hero — Pitons from sea or viewpoint |
| `pitons-viewpoint.jpg` | Pitons tour cards and CTAs |
| `soufriere-volcano.jpg` | Soufrière / Sulphur Springs content |
| `catamaran-pitons.jpg` | Catamaran page hero and cards |
| `cruise-port-castries.jpg` | Port guide and cruise port sections |

## Current placeholders

The site uses existing Caribbean stock images (`hero-catamaran.jpg`, `cruise-port.jpg`, etc.) until St Lucia photography is added. Update `alt` text in `content/*.html` and hero partials when swapping files.

## Replicating for a new cruise port

1. Copy this folder structure.
2. Replace image filenames in `partials/hero-*.html` and `content/*.html`.
3. Update `cta-photo-bg-*` classes in `css/site.css` background URLs.
